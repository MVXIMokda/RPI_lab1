# Лабораторная работа №1

**Предмет:** разработка пользовательского интерфейса.

**Тема:** создание и настройка окружения, компоненты React и CSS.

В презентации задания №1 и №2 относятся к одной лабораторной работе №1.
Задание №2 — сайт об известном деятеле.

## Короткий текст для защиты

### Задание №1

> Выполнена декомпозиция приложения «Академия Кода»: навигация вынесена в Navbar, страницы Home, About и Contacts — в отдельные файлы, оформление — в CSS. В App хранится состояние текущего раздела через useState. Нажатие кнопки Navbar меняет это состояние, после чего React отображает соответствующий компонент страницы. Связь между App и Navbar организована через props. Наведение реализовано через :hover, без JavaScript-обработчиков. Сторонняя библиотека маршрутизации не используется.

Показать в браузере переключение трёх страниц. В редакторе открыть `src/App.jsx`, `src/components/Navbar/`, `src/pages/` и `src/styles/` внутри `task-1`.

### Задание №2

> Подготовлен сайт об Алане Тьюринге. Он разделён на PersonCard с ФИО, фото и ссылкой, Biography с биографией и научными работами и Navigation с навигацией и переключателем темы. У каждого компонента своя папка с JSX и CSS. Первый труд выделен псевдоклассом :first-child. Кнопки раскрывают биографические подробности и награды через изменение состояния useState. Светлая и тёмная темы реализованы CSS-переменными; useEffect синхронизирует выбранную тему с атрибутом HTML и localStorage, поэтому выбор сохраняется после обновления страницы. Сайт адаптирован под узкие экраны.

Показать навигацию, раскрытие блоков, переключение темы и обновление страницы. Затем открыть папки компонентов и селектор `.works-list li:first-child` в `Biography.css` внутри `task-2`.

Полная [памятка запуска и остановки всех работ](docs/running.md) находится в этом репозитории.

## Запуск

Требуется Node.js 22.13+ (ветка 22) или 24+ и npm. Все команды выполняются из этой папки:

```bash
npm ci
npm run dev:task1
```

Задание 1: http://127.0.0.1:5173.

Во втором терминале из этой же папки:

```bash
npm run dev:task2
```

Задание 2: http://127.0.0.1:5174. Серверы слушают только локальный интерфейс.
Остановка каждого сервера — Ctrl+C.

Для остановки обоих заданий нажать Ctrl+C в каждой из двух вкладок терминала.
Закрытие вкладки браузера сервер не останавливает. Для повторного запуска достаточно той же команды `npm run dev:task1` или `npm run dev:task2`.
Если порт уже занят, нужное приложение может быть запущено ранее — проверить адрес в браузере или остановить его прежний сервер.

```bash
npm run lint
npm run build
```

Сборки появятся в `task-1/dist` и `task-2/dist`. Их нужно открывать через HTTP-сервер,
например `npm run preview --workspace task-2`, а не двойным щелчком по index.html.

## Задание №1 — декомпозиция «Академии Кода»

[Требования к заданию и структура файлов](docs/requirements.md).

- `task-1/src/components/Navbar/` — навигация и её CSS.
- `task-1/src/pages/` — Home, About и Contacts.
- `task-1/src/styles/` — общие стили и оформление страниц.
- `task-1/src/App.jsx` — состояние текущей страницы и выбор компонента через объект `pages`.

Все inline-стили перенесены в CSS, наведение реализовано через `:hover`.
Сторонние библиотеки компонентов и маршрутизации не используются.
Сайт содержит три страницы: главную, информацию об академии и контакты. Контактные данные демонстрационные.
Кнопки «Подробнее» заменены ссылками на документацию соответствующих технологий.

## Задание №2 — Алан Тьюринг

- `PersonCard/` — ФИО, локальный портрет, годы жизни, ссылка «Подробнее».
- `Biography/` — биография, труды, раскрывающиеся подробности и награды.
- `Navigation/` — навигация по разделам и переключатель темы.
- Каждый из этих компонентов находится в собственной папке с `.jsx` и `.css`.
- Первый труд выделяется исключительно селектором `li:first-child`.
- Тема сохраняется в localStorage; при первом запуске учитывается системная тема.
- Навигация — обычные якорные ссылки, раскрытие блоков — React `useState`.
- Добавлены адаптивная вёрстка, видимый фокус, подписи кнопок и `aria-expanded`.

Сайт работает без внешних API и CDN: фото хранится в `public/`.
Опционально реализовано переключение подробностей биографии.
Форма обратной связи и запросы к API Википедии не входят в эту версию.
