# Краткий разбор для защиты

## Задание 1

**Что такое декомпозиция?** Разделение большого компонента на небольшие компоненты с понятными обязанностями.
В исходнике навигация, три страницы и объект стилей находились вместе. Теперь у них отдельные файлы.

**Как переключаются страницы?** `useState('home')` хранит ключ текущего раздела.
Navbar получает ключ и функцию обновления через props. Клик вызывает `onNavigate(id)`.
В `App.jsx` выражение `pages[currentSection]` выбирает компонент из объекта; `<Page />` выводит его.
Перезагрузка документа не нужна. После полной перезагрузки снова показывается Главная.

**Почему нет react-router-dom?** По условию нельзя применять сторонние библиотеки React.
Для трёх экранов достаточно локального состояния. Адрес браузера при переключении не изменяется.

**Как работает наведение?** CSS-псевдокласс `:hover` применяется браузером при наведении указателя.
Обработчики `onMouseOver` и `onMouseOut` не нужны.

**Что передаётся через props?** Данные и функции от родительского компонента дочернему.
Navbar не хранит копию состояния текущего раздела, поэтому оно не рассинхронизируется с App.

## Задание 2

**Какие компоненты созданы?** PersonCard выводит сведения и фото; Biography — основной материал;
Navigation — ссылки на разделы и кнопку темы. Рядом с каждым JSX лежит его CSS.

**Как выделяется первый пункт?** `.works-list li:first-child` выбирает первый дочерний `li`.
В JSX нет проверки `index === 0`, отдельного класса первого пункта или inline-стиля.

**Как раскрываются награды?** Булево состояние `showHonours` меняется после клика.
У списка изменяется атрибут `hidden`, у кнопки — `aria-expanded` и видимая подпись.
Аналогично работает раскрытие подробностей биографии.

**Как устроена тема?** Состояние `theme` принимает `light` или `dark`.
`useEffect` записывает значение в `data-theme` корневого HTML-элемента и в localStorage.
CSS переопределяет переменные фона, текста, акцента и границ.
При повторном открытии выбирается сохранённая тема; если сохранения нет — системная.
Если браузер запрещает localStorage, интерфейс продолжает работать без сохранения.

**Как работает навигация?** Ссылки ведут на id разделов в пределах одного документа.
`scroll-behavior: smooth` включает плавную прокрутку, а при предпочтении reduced motion она отключается.

**Почему изображение локальное?** После установки зависимостей сайт не требует доступа к внешним серверам для отображения портрета.
